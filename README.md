# Aura News Portal

A sleek, responsive, and aesthetic dark-themed Online News Portal. Built to display top headlines, various news categories, trending stories, and a fully functional frontend contact form.

## Features
- **Dark Theme Interface**: Aesthetic, modern UI using slate colors and bold accents.
- **Hero Section**: Displays the top headline dynamically.
- **Category Tags**: Distinct colors for Tech, World, and Sports.
- **Trending Sidebar**: A stylish ordered list for trending news articles.
- **Responsive Layout**: Adapts perfectly to desktops, tablets, and mobile screens.
- **Interactive Form**: Frontend JavaScript form handling that shows a success message ("Your response has been recorded") upon submission without page reload.

## Tech Stack Used
- HTML5 (Semantic elements)
- CSS3 (Flexbox, CSS Grid, Custom Variables)
- Vanilla JavaScript (Event handling, DOM manipulation)

## How to Run
1. Create a folder named `NewsPortal`.
2. Save the provided files inside this folder exactly as:
   - `index.html`
   - `style.css`
   - `index.js`
3. Simply double-click on `index.html` to open it in any modern web browser (Chrome, Edge, Firefox, etc.). No local server required.
